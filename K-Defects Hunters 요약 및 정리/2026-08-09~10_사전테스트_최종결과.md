## 3. 8/10 결과 — 배포 파이프라인 연습

### 목표 달성

**"GitHub Actions 버튼 하나로 서버에 배포되고, 브라우저에서 응답이 보인다"** — 달성.

```
push → Run workflow 클릭 → GitHub 러너가 SSH 접속 →
git pull → docker build → 컨테이너 교체 → 자체 헬스체크 → 성공 표시
```

최종 실행: `deploy #1 succeeded in 17s`, `{"status":"ok"}` 확인.

### 발견한 문제 8건 (재사용 가능한 지식)

| # | 문제 | 원인 | 해결 |
|---|---|---|---|
| 1 | `docker` 명령 없음 (로컬) | Docker Desktop 미설치 | 서버 빌드로 대체 |
| 2 | `Author identity unknown` | git 사용자 정보 미설정 | `git config --global` |
| 3 | `Dockerfile.txt` 생성 | notepad 자동 확장자 | `ren`으로 제거 |
| 4 | **`docker build` 중 Killed (exit 137)** | 512MB RAM 부족(OOM) | 스왑 1GB 추가 |
| 5 | 외부 접속 `ERR_CONNECTION_TIMED_OUT` | Lightsail 방화벽 미등록 | 포트 규칙 추가 |
| 6 | 방화벽 규칙 저장 안 됨 | 소스 IP 미입력 | `0.0.0.0/0` 입력 |
| 7 | Secrets 메뉴 못 찾음 | 계정 설정 vs 저장소 설정 혼동 | 저장소 Settings 하위 확인 |
| 8 | Actions에 워크플로우 안 보임 | `.github/` push 누락 | commit/push 재확인 |

**#4가 가장 중요한 발견이다.** 순수 FastAPI+uvicorn 빌드조차 512MB에서 스왑 없이 실패했다.
→ **화요일 4GB 인스턴스 결정이 사양 측면에서 타당함을 실증적으로 확인.**
