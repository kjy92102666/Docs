• 모든 PCB를 작업자가 최종 판정한다면 상태 흐름을 아래처럼 잡는 것이 가장 정확합니다.                            
                                                                                                                 
  기존 배치 상태를 최대한 유지하는 방법을 권장합니다.                                                            
                                                                                                                 
  - INSPECTING: AI 검사 중                                                                                       
  - INSPECTED: AI 검사는 끝났지만 작업자 판정이 남은 상태                                                        
  - COMPLETED: 모든 PCB의 작업자 판정까지 끝난 상태                                                              
                                                                                                                 
  별도로 REVIEWING 상태를 추가하는 방법도 있지만, DB 마이그레이션과 프론트·백엔드 변경 범위가 커집니다. INSPECTED
  상태에서 판정 건수로 “판정 대기/진행 중”을 구분하는 편이 단순합니다.                                           
                                                                                                                 
  # 전체 프로세스별 상태값                                                                                       
                                                                                                                 
  ## 1. 검사계획·입고 배치 등록                                                                                  
                                                                                                                 
  이 부분까지는 사용자가 작업한 범위입니다.                                                                      
                                                                                                                 
  ### 검사계획 상태                                                                                              
                                                                                                                 
  PLANNED                                                                                                        
  검사계획 등록 완료, 입고 배치 미등록                                                                           
                                                                                                                 
  → BATCH_CREATED                                                                                                
  입고 배치와 PCB 생성 완료                                                                                      
                                                                                                                 
  → CANCELLED                                                                                                    
  검사계획 취소                                                                                                  
                                                                                                                 
  ### 입고 배치 상태                                                                                             
                                                                                                                 
  CREATED                                                                                                        
  입고 배치 생성 완료, 검사 담당자 인계 대기                                                                     

  CREATED 배치와 inspection_ready = true가 검사 담당자의 입력 조건입니다.                                        
                                                                                                                 
  ———                                                                                                            
                                                                                                                 
  ## 2. 검사 시작 가능 상태                                                                                      
                                                                                                                 
  검사 시작 조건은 다음과 같습니다.                                                                              
                                                                                                                 
  batch.status = CREATED                                                                                         
  inspection_ready = true                                                                                        
  PCB 수 = batch_size                                                                                            
  모든 PCB 이미지 연결 완료                                                                                      
  실제 이미지 파일 접근 가능                                                                                     
                                                                                                                 
  조건을 충족하지 못하면 검사를 시작하지 않습니다.                                                               
                                                                                                                 
  화면 표시:                                                                                                     
                                                                                                                 
  - inspection_ready = true → 검사 준비 완료                                                                     
  - inspection_ready = false → 검사 준비 미완료                                                                  
                                                                                                                 
  ———                                                                                                            
                                                                                                                 
  ## 3. AI 검사 시작                                                                                             
                                                                                                                 
  작업자가 검사 시작을 누르면 배치를 다음 상태로 전환합니다.                                                     
                                                                                                                 
  CREATED → INSPECTING                                                                                           
                                                                                                                 
   상태값        화면 표시     의미                                                                              
  ━━━━━━━━━━━━  ━━━━━━━━━━━━  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━                                                   
   INSPECTING    AI 검사 중    PCB별 AI 추론과 결과 저장 진행                                                    
                                                                                                                 
  공정상태 화면에서 필요한 진행 값:                                                                              
                                                                                                                 
  - 전체 PCB 수                                                                                                  
  - AI 검사 완료 PCB 수                                                                                          
  - AI 검사 진행률                                                                                               
  - 현재 검사 중인 PCB                                                                                           
  - 검사 시작 시각                                                                                               
                                                                                                                 
  AI 검사 진행률 = inspection_result 수 / batch_size                                                             
                                                                                                                 
  현재처럼 INSPECTING과 INSPECTED를 하나의 트랜잭션에서 처리하면 화면이 중간 상태를 볼 수 없으므로, 검사 시작 상 
  태는 먼저 저장·커밋되어야 합니다.                                                                              
                                                                                                                 
  ———                                                                                                            
                                                                                                                 
  ## 4. PCB별 AI 판정                                                                                            
                                                                                                                 
  AI는 각 PCB에 대해 정상 또는 불량 후보를 출력합니다.                                                           
                                                                                                                 
   AI 판정         저장 기준                                                                                     
  ━━━━━━━━━━━━━━  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━                                                                   
   AI 정상         detected_is_defect = false                                                                    
  ──────────────  ────────────────────────────                                                                   
   AI 불량 후보    detected_is_defect = true                                                                     
                                                                                                                 
  함께 저장할 값:                                                                                                
                                                                                                                 
  - pcb_id                                                                                                       
  - detected_is_defect                                                                                           
  - detected_defect_type                                                                                         
  - confidence_score                                                                                             
  - inspected_at                                                                                                 
                                                                                                                 
  이 단계에서는 AI가 정답을 확정한 것이 아닙니다. 따라서 TP, TN, FP, FN은 아직 확정할 수 없습니다.               
                                                                                                                 
  현재 코드처럼 더미 데이터의 정답을 이용해 AI 검사 시점에 result_type을 생성하는 방식은 시뮬레이션 평가용으로만 
  사용해야 합니다.                                                                                               
                                                                                                                 
  ———                                                                                                            
                                                                                                                 
  ## 5. 모든 PCB의 작업자 판정 항목 생성                                                                         
                                                                                                                 
  AI 불량 후보뿐만 아니라 모든 PCB에 작업자 판정 항목을 생성합니다.                                              
                                                                                                                 
  작업자 판정 초기 상태:                                                                                         
                                                                                                                 
  PENDING                                                                                                        
                                                                                                                 
  배치 수량이 100개라면 작업자 판정 항목도 100개가 생성됩니다.                                                   
                                                                                                                 
  inspection_result 100건                                                                                        
  inspection_review 100건                                                                                        
  모든 review 상태 = PENDING                                                                                     
                                                                                                                 
  현재 defect_review는 불량 후보에만 생성되므로 이 정책과 맞지 않습니다. 모든 PCB를 검토하려면 전체              
  inspection_result에 대응하는 검토 레코드가 필요합니다.                                                         
                                                                                                                 
  ———                                                                                                            
                                                                                                                 
  ## 6. AI 검사 종료                                                                                             
                                                                                                                 
  모든 PCB의 AI 검사 결과와 작업자 판정 항목 생성이 끝나면:                                                      
                                                                                                                 
  INSPECTING → INSPECTED                                                                                         
                                                                                                                 
  INSPECTED의 의미는 다음과 같이 정의합니다.                                                                     
                                                                                                                 
  > AI 검사는 모두 끝났으며, 작업자 최종 판정이 남아 있는 상태                                                   
                                                                                                                 
  화면 표시는 판정 진행 건수에 따라 나눕니다.                                                                    
                                                                                                                 
   조건              화면 표시                                                                                   
  ━━━━━━━━━━━━━━━━  ━━━━━━━━━━━━━━━━━━                                                                           
   판정 완료 0건     작업자 판정 대기                                                                            
  ────────────────  ──────────────────                                                                           
   일부 판정 완료    작업자 판정 중                                                                              
  ────────────────  ──────────────────                                                                           
   모든 판정 완료    검사 완료                                                                                   
                                                                                                                 
  DB 상태는 처음 두 경우 모두 INSPECTED를 유지합니다.                                                            
                                                                                                                 
  ———                                                                                                            
                                                                                                                 
  ## 7. 작업자 최종 판정 상태                                                                                    
                                                                                                                 
  모든 PCB의 초기 판정 상태는 PENDING입니다.                                                                     
                                                                                                                 
  최종 상태는 다음 3개입니다.                                                                                    
                                                                                                                 
   상태값              화면 표시    의미                                                                         
  ━━━━━━━━━━━━━━━━━━  ━━━━━━━━━━━  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━                             
   CONFIRMED_NORMAL    정상         작업자가 정상 PCB로 최종 판정                                                
  ──────────────────  ───────────  ─────────────────────────────────────────────────                             
   CONFIRMED_DEFECT    불량         작업자가 실제 불량으로 최종 판정                                             
  ──────────────────  ───────────  ─────────────────────────────────────────────────                             
   FALSE_ALARM         오탐         AI가 불량으로 검출했지만 작업자가 정상으로 판정                              
  ──────────────────  ───────────  ─────────────────────────────────────────────────                             
   PENDING             판정 대기    아직 작업자가 확인하지 않음                                                  
                                                                                                                 
  ### AI 정상 판정 PCB                                                                                           
                                                                                                                 
  작업자에게 다음 버튼을 제공합니다.                                                                             
                                                                                                                 
  [정상 확정] [불량 확정]                                                                                        
                                                                                                                 
  - 정상 확정 → CONFIRMED_NORMAL                                                                                 
  - 불량 확정 → CONFIRMED_DEFECT                                                                                 

  ### AI 불량 후보 PCB                                                                                           
                                                                                                                 
  작업자에게 다음 버튼을 제공합니다.                                                                             
                                                                                                                 
  [불량 확정] [오탐 처리]                                                                                        
                                                                                                                 
  - 불량 확정 → CONFIRMED_DEFECT                                                                                 
  - 오탐 처리 → FALSE_ALARM                                                                                      
                                                                                                                 
  이렇게 해야 정상과 오탐을 구분할 수 있습니다.                                                                  
                                                                                                                 
  - 정상: AI도 정상, 작업자도 정상                                                                               
  - 오탐: AI는 불량, 작업자는 정상                                                                               
                                                                                                                 
  ———                                                                                                            
                                                                                                                 
  ## 8. AI 성능 평가값 확정                                                                                      
                                                                                                                 
  TP, TN, FP, FN은 작업자 판정 이후 확정합니다.                                                                  
                                                                                                                 
   AI 판정      작업자 판정         최종 result_type                                                             
  ━━━━━━━━━━━  ━━━━━━━━━━━━━━━━━━  ━━━━━━━━━━━━━━━━━━                                                            
   정상         CONFIRMED_NORMAL    TN                                                                           
  ───────────  ──────────────────  ──────────────────                                                            
   정상         CONFIRMED_DEFECT    FN                                                                           
  ───────────  ──────────────────  ──────────────────                                                            
   불량 후보    CONFIRMED_DEFECT    TP                                                                           
  ───────────  ──────────────────  ──────────────────                                                            
   불량 후보    FALSE_ALARM         FP                                                                           
                                                                                                                 
  따라서 작업자 판정이 PENDING일 때는 result_type도 미확정 상태여야 합니다.                                      
                                                                                                                 
  현재 inspection_result.result_type은 NOT NULL이므로 실제 AI 연동 전에 DB 담당자와 변경을 협의해야 합니다.      
                                                                                                                 
  ———                                                                                                            
                                                                                                                 
  ## 9. 작업자 판정 진행                                                                                         
                                                                                                                 
  작업자가 PCB 한 건을 판정할 때마다 다음 값을 다시 계산합니다.                                                  
                                                                                                                 
  - 전체 PCB 수                                                                                                  
  - 판정 완료 수                                                                                                 
  - PENDING 수                                                                                                   
  - 정상 수                                                                                                      
  - 불량 수                                                                                                      
  - 오탐 수                                                                                                      
                                                                                                                 
  판정 진행률 = 판정 완료 수 / batch_size                                                                        
                                                                                                                 
  배치 상태 전환 기준:                                                                                           
                                                                                                                 
  PENDING > 0                                                                                                    
  → 배치 INSPECTED 유지                                                                                          
                                                                                                                 
  PENDING = 0                                                                                                    
  → 배치 COMPLETED 전환                                                                                          
                                                                                                                 
  작업자 판정 저장과 마지막 배치 COMPLETED 전환은 같은 DB 트랜잭션에서 처리해야 합니다.                          
                                                                                                                 
  ———                                                                                                            
                                                                                                                 
  ## 10. 검사 최종 완료                                                                                          
                                                                                                                 
  모든 PCB의 작업자 판정이 끝났을 때만:                                                                          
                                                                                                                 
  INSPECTED → COMPLETED                                                                                          
                                                                                                                 
   상태값       화면 표시    의미                                                                                
  ━━━━━━━━━━━  ━━━━━━━━━━━  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━                                                   
   COMPLETED    검사 완료    모든 PCB의 작업자 최종 판정 완료                                                    
                                                                                                                 
  완료 조건:                                                                                                     
                                                                                                                 
  inspection_result 수 = batch_size                                                                              
  review 수 = batch_size                                                                                         
  PENDING 수 = 0                                                                                                 
                                                                                                                 
  AI 불량 후보가 0건이어도 자동 완료하지 않습니다.                                                               
                                                                                                                 
  AI 판정이 전부 정상                                                                                            
  → 모든 PCB 작업자 판정 PENDING                                                                                 
  → 작업자가 모두 정상/불량으로 확인                                                                             
  → COMPLETED                                                                                                    
                                                                                                                 
  ———                                                                                                            
                                                                                                                 
  # 최종 상태 전이                                                                                               
                                                                                                                 
  [검사계획·배치 등록]                                                                                           
                                                                                                                 
  PLANNED                                                                                                        
  → BATCH_CREATED                                                                                                
  → production_batch.CREATED                                                                                     
                                                                                                                 
                                                                                                                 
  [AI 검사]                                                                                                      
                                                                                                                 
  CREATED + inspection_ready                                                                                     
  → INSPECTING                                                                                                   
  → INSPECTED                                                                                                    
                                                                                                                 
                                                                                                                 
  [작업자 최종 판정]                                                                                             
                                                                                                                 
  모든 PCB PENDING                                                                                               
  → CONFIRMED_NORMAL                                                                                             
  → CONFIRMED_DEFECT                                                                                             
  → FALSE_ALARM                                                                                                  
                                                                                                                 
  PENDING 0건                                                                                                    
  → production_batch.COMPLETED                                                                                   
                                                                                                                 
  # 공정상태 화면에 전달할 값                                                                                    
                                                                                                                 
  배치 기준:                                                                                                     
                                                                                                                 
  - batch_id                                                                                                     
  - batch_code                                                                                                   
  - line_id                                                                                                      
  - status                                                                                                       
  - batch_size                                                                                                   
  - ai_inspected_count                                                                                           
  - reviewed_count                                                                                               
  - pending_count                                                                                                
  - normal_count                                                                                                 
  - defect_count                                                                                                 
  - false_alarm_count                                                                                            
  - inspection_started_at                                                                                        
  - inspection_completed_at                                                                                      
                                                                                                                 
  PCB 기준:                                                                                                      
                                                                                                                 
  - pcb_id                                                                                                       
  - ai_status                                                                                                    
  - detected_is_defect                                                                                           
  - detected_defect_type                                                                                         
  - confidence_score                                                                                             
  - review_status                                                                                                
  - reviewed_at                                                                                                  
  - reviewed_by                                                                                                  
  - result_type                                                                                                  
                                                                                                                 
  이 상태 모델에서는 검사 담당자 범위가 명확하게 다음으로 한정됩니다.                                            
                                                                                                                 
  CREATED 배치 인수                                                                                              
  → INSPECTING                                                                                                   
  → INSPECTED                                                                                                    
  → 모든 PCB 작업자 판정                                                                                         
  → COMPLETED
