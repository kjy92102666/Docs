# PCB MES 발표 시연 타임라인

> 목표 시간: 약 8~9분 (권장 7~10분 범위 내)
> 화면 녹화 또는 라이브 시연 시 그대로 큐시트로 사용 가능

---

## 시연 전 준비 체크리스트

- [ ] **브라우저 2개 준비**: 하나는 계속 공정상태 화면 고정용 (새로고침/화면전환 시 AGV 대기존 애니메이션이 처음부터 재생되는 특성이 있어, 시연 도중 이 화면을 벗어났다가 돌아오지 않도록 별도 창으로 띄워둠)
- [ ] **사전에 검사 완료된 배치 1개 준비** — 화면 4(검사결과·검수) 시연용으로, NG가 몇 건 포함된 배치를 미리 만들어둠
- [ ] **사전에 분석 데이터가 쌓인 상태 확인** — 화면 7(분석정보) Pareto/히트맵이 빈 화면으로 안 뜨도록
- [ ] 시연용 배치는 **라인이 비어있는 상태**에서 등록 시작 (WAITING 상태로 시작하면 "검사 시작" 버튼이 비활성화되어 있고 "검사 라인에 도착한 뒤 검사를 시작할 수 있습니다" 안내가 뜨는데, 이건 정상 동작이니 당황하지 않기)
- [ ] 하드 리프레시 한번 해두고 시작 (캐시된 옛 화면 방지)

| 1:55–2:25 | ② 검사등록 — 배치 | 방금 만든 계획 선택 → 입고 배치 생성 클릭 | "배치는 실제 검사 대상 PCB와 이미지를 묶은 실행 단위입니다." | 배치 코드 발급, batched_pcb 자동 생성 |
| 2:25–3:15 | ③ 공정상태 (1차) | (브라우저 2 전환) 방금 만든 배치가 라인으로 이동하는 AGV 애니메이션 확인. 라인 DETAIL 패널 클릭해서 상세 정보 보여주기 | "이 화면은 실제 하드웨어 제어가 아니라 배치 상태전이와 프론트 시뮬레이션을 결합한 디지털 트윈입니다. AGV가 실제로 도착을 완료해야만 라인이 점유 상태로 바뀝니다." | 상태 기반 연계(차별점 4번), 라인 클릭 시 실시간 드릴다운 |
| 3:15–4:45 | ④ 불량검사 — 실시간 검사 | 배치 카드 선택(라인 도착 확인된 것) → 검사 시작 버튼 → PCB가 순서대로 넘어가는 캐러셀, 진행률, Bounding Box 확인 | "검사 시작을 누르면 백엔드가 PCB를 순차적으로 YOLO에 전달하고, WebSocket으로 실시간 진행 상황을 보내옵니다. 새로고침 없이 현재 검사 위치와 판정을 바로 확인할 수 있습니다." | WebSocket 실시간성, 고해상도 이미지를 3×3 타일로 나눠 작은 결함도 놓치지 않는 점 |
| 4:45–5:45 | ⑤ 불량검사 — 검사결과·검수 | 사전 준비된 완료 배치 선택 → NG 목록에서 하나 클릭 → Bounding Box 토글 → AI 판정 승인 / 유형 수정 / 오탐 처리 각각 한 번씩 시연 | "AI 판정을 그대로 최종 결과로 쓰지 않고 작업자가 확인합니다. 이 승인·수정·오탐 데이터가 다시 분석과 재학습 판단에 쓰입니다." | Human-in-the-loop (차별점 2번) — 발표에서 가장 강조할 부분 |
| 5:45–6:15 | ③ 공정상태 (2차) | 브라우저 2에서 검사 완료된 배치가 버퍼로 이동 → 최종 적재 도크로 이동하는 것 확인 | "검사가 끝나면 AGV가 버퍼(16슬롯)를 거쳐 최종 적재 구역으로 이송합니다." | 버퍼 슬롯 상태(EMPTY/RESERVED/OCCUPIED) 잠깐 짚기 |
| 6:15–7:00 | ⑥ 재고관리 | 인계 대기 배치 선택 → 필요 자재 소요량/보유량/판정(ENOUGH/ORDER_NEED/PENDING) 확인 → SMD 인계 버튼 클릭 | "정상 PCB 수량을 BOM과 연결해서, 검사가 끝나면 바로 다음 공정 진행 가능 여부까지 판단합니다." | 품질검사 결과가 재고 판단까지 이어진다는 것 |

## 시간이 부족할 때 줄이는 순서 (우선순위 낮은 것부터)

1. 리포트 내보내기 (8:05 부분 생략, 언급만)
2. 챗봇 질의 (한 줄 언급으로 대체)
3. 분석정보 — Pareto/히트맵 중 하나만
4. 공정상태 2차 확인 생략(1차만)

## 시간이 남을 때 추가할 수 있는 것

- 검사계획 취소(소프트 삭제) 시연 — CANCELLED 상태로 바뀌는 것 짧게 보여주기
- 재고 부족(PENDING) 배치의 인계 버튼이 비활성화되는 것 보여주기 (안전장치 어필)
- 여러 브라우저 동시 접속 시 상태가 동기화되는 것 짧게 시연 (다중 사용자 실시간 동기화 강조)

## 리허설 시 반드시 확인할 것

- [ ] 검사 시작 직후 곧바로 검사화면으로 넘어갔을 때 이미지가 정상적으로 뜨는지 (배치 등록 → 검사화면 직행 시 로딩이 늦어질 수 있음, 늦어도 몇 초 내 자동 복구되는지)
- [ ] 공정상태 화면에서 무관한 배치를 등록해도 이미 대기 중인 AGV가 재이동하지 않는지
- [ ] 전체 타임라인을 실제로 한 번 통으로 리허설해서 8~9분 안에 들어오는지 시간 체크
