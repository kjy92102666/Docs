# PCB MES 발표 시연 타임라인

> 목표 시간: 약 5~6분
> 화면 녹화 또는 라이브 시연 시 그대로 큐시트로 사용 가능

---

## 시연 전 준비 체크리스트

- [ ] **브라우저 2개 준비**: 하나는 계속 공정상태 화면 고정용 (새로고침/화면전환 시 AGV 대기존 애니메이션이 처음부터 재생되는 특성이 있어, 시연 도중 이 화면을 벗어났다가 돌아오지 않도록 별도 창으로 띄워둠)
- [ ] **사전에 검사 완료된 배치 1개 준비** — 화면 5(검사결과·검수)용, NG가 몇 건 포함된 배치를 미리 만들어둠
- [ ] **사전에 버퍼/최종적재에 배치가 이미 몇 개 도착해 있는 상태 준비** — 공정상태 화면에서 새로 이동시키지 않고도 버퍼·적재 흐름을 "이미 있는 상태"로 바로 보여주기 위함(시간 절약)
- [ ] **사전에 분석 데이터가 쌓인 상태 확인** — 분석정보 Pareto/히트맵이 빈 화면으로 안 뜨도록
- [ ] 시연용 신규 배치는 **라인이 비어있는 상태**에서 등록 시작 (WAITING 상태로 시작하면 "검사 시작" 버튼이 비활성화되어 있고 "검사 라인에 도착한 뒤 검사를 시작할 수 있습니다" 안내가 뜨는데, 정상 동작이니 당황하지 않기)
- [ ] 하드 리프레시 한번 해두고 시작 (캐시된 옛 화면 방지)

---

## 타임라인 (5:30 기준, 여유 30초는 화면 전환/버퍼)

| 시간 | 화면 | 액션 | 멘트 | 강조 포인트 |
|---|---|---|---|---|

## 6분까지 여유 있을 때 추가할 것 (우선순위 순)

1. 검사결과·검수에서 승인/수정/오탐 3가지 다 시연 (지금은 1~2개만)
2. 분석정보에서 Pareto + 히트맵 둘 다 보여주기
3. 재고 부족(PENDING) 배치의 인계 버튼 비활성화 잠깐 보여주기 (안전장치 어필)

## 5분 밑으로 더 줄여야 할 때 (우선순위 낮은 것부터 제거)

1. 챗봇 시연 삭제 (기능 존재만 구두 언급)
2. 분석정보를 매트릭스 없이 Pareto/히트맵 하나만
3. 검사결과·검수에서 승인만 1건 클릭하고 나머지(수정/오탐)는 "이런 것도 가능합니다"로 구두 설명
4. 공정상태 화면 확인을 15초 이내로 압축(배치 이동 애니메이션 대신 이미 도착해 있는 정지 화면 위주로)

## 리허설 시 반드시 확인할 것

- [ ] 전체 타임라인을 실제로 통으로 리허설해서 5:30~6:00 안에 들어오는지 시간 체크 (초반 몇 번은 예상보다 오래 걸리는 경우가 많음)
- [ ] 검사 시작 직후 곧바로 검사화면으로 넘어갔을 때 이미지가 정상적으로 뜨는지
- [ ] 공정상태 화면에서 무관한 배치를 등록해도 이미 대기 중인 AGV가 재이동하지 않는지
- [ ] 사전 준비 데이터(완료 배치, 분석 데이터, 버퍼/적재 상태)가 리허설 중 실수로 초기화되지 않았는지 발표 직전 재확인
