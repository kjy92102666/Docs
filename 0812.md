
• 공정상태 규칙을 코드 기준으로 정리하고, BATCH-20260811-0014 버그도 수정했습니다.
                                                                                                                          
  ### 공정상태 규칙                                                                                                       
                                                                                                                          
  - 배치 등록                                                                                                             
      - 생산계획이 PLANNED이고 대상 라인·모델·수량이 유효해야 합니다.                                                     
      - 수량은 1~500개입니다.                                                                                             
      - 빈 라인: LINE_ASSIGNED                                                                                            
      - 사용 중인 라인: CREATED 대기 배치                                                                                 
      - 라인당 활성 배치 1개 + 대기 배치 1개만 허용                                                                       
      - 다른 모델이면 LINE_MODEL_CONFLICT                                                                                 
      - 대기 슬롯이 차 있으면 LINE_WAITING_SLOT_FULL                                                                      
                                                                                                                          
  - 검사 시작 조건                                                                                                        
      - LINE_ASSIGNED                                                                                                     
      - PCB 수량이 배치 수량과 일치                                                                                       
      - 모든 PCB에 이미지가 연결됨                                                                                        
      - 실제 데이터셋 이미지가 존재함                                                                                     
      - INSPECTING 상태는 실행 중 작업이 확인될 때만 비활성                                                               
      - 실패 작업(FAILED) 또는 고아 작업(STALE)은 재시작 가능                                                             
                                                                                                                          
  - AGV 이동                                                                                                              
      - 전담 AGV 우선, 없으면 지원 AGV 사용                                                                               
      - 대기 배치는 Waiting Zone에서 대기                                                                                 
      - 검사 완료 후 TO_POST_INSPECTION_BUFFER                                                                            
      - 버퍼 도착 후 라인 해제 및 다음 대기 배치 승격                                                                     
      - 최종 판정 완료 후 TO_FINAL_DOCK → FINAL_DOCK                                                                      
                                                                                                                          
  - 라인 작동/비작동                                                                                                      
      - 작동: LINE_ASSIGNED + LINE, 검사 시작 가능                                                                        
      - 검사 중: INSPECTING + LINE                                                                                        
      - 검사 완료: INSPECTED + LINE, 후속 AGV 이동 대기                                                                   
      - 버퍼가 가득 차면 라인을 계속 점유하고 다음 배치를 승격하지 않음                                                   
      - COMPLETED, CANCELLED는 라인 점유에서 제외                                                                         
                                                                                                                          
  - 메시지 표출                                                                                                           
      - 검사 중: 검사가 진행 중입니다.                                                                                    
      - PCB 로딩 중: PCB 검사 데이터를 불러오는 중입니다.                                                                 
      - 라인 대기: 검사 라인에 도착한 뒤 검사를 시작할 수 있습니다.                                                       
      - 작업 상태 불일치: 검사 작업 상태를 확인 중입니다.                                                                 
                                                                                                                          
  ### BATCH-20260811-0014 원인                                                                                            
                                                                                                                          
  공정상태 화면 자체가 검사 버튼을 직접 변경하지는 않습니다. 문제의 실제 원인은 다음 상태가 서로 분리되어 있었기 때문입니 
  다.                                                                                                                     
                                                                                                                          
  - DB 배치 상태: INSPECTING                                                                                              
  - 검사 작업 상태: 서버 프로세스 메모리의 job 상태                                                                       
  - 작업이 사라지거나 다른 프로세스에서 조회되면 job 상태가 IDLE처럼 반환됨                                               
  - 프론트가 INSPECTING + IDLE을 검사 시작 가능으로 잘못 판단                                                             
                                                                                                                          
  따라서 공정상태 화면 동시 접속은 원인이라기보다 이 상태 불일치를 드러내는 조건이었습니다.                               
                                                                                                                          
  ### 적용한 수정                                                                                                         
                                                                                                                          
  - INSPECTING 배치에 job이 없으면 백엔드가 STALE 반환                                                                    
  - 프론트는 INSPECTING + IDLE이면 검사 시작 버튼 비활성화                                                                
  - FAILED 또는 STALE일 때만 재시작 허용                                                                                  
  - 비활성 사유를 화면에 표시                                                                                             
  - 관련 회귀 테스트 추가                                                                                                 
                                                                                                                          
  검증 결과:                                                                                                              
                                                                                                                          
  - 프론트 관련 테스트 12개 통과                                                                                          
  - 공정상태/WebSocket 테스트 20개 통과                                                                                   
  - 백엔드 검사·공정상태 테스트 40개 통과                                                                                 
  - 프론트 production build 성공                                                                                          
                                                                                                                          
  변경사항은 커밋하지 않았고, 기존 작업 트리 변경사항은 유지했습니다.
